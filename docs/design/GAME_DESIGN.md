## 🎯 游戏概述

### 游戏类型
- **类型**: 2D挂机放置类修仙游戏
- **平台**: Node.js / 浏览器 / 抖音小游戏
- **开发语言**: TypeScript

### 游戏目标
玩家通过挂机自动战斗，不断提升境界和实力，从凡人修炼成仙。

### 目标用户
- 喜欢挂机放置游戏的玩家
- 修仙题材爱好者
- 休闲游戏玩家

## 🎮 核心玩法

### 1. 自动战斗

**核心机制**:
- 每秒自动战斗一次
- 根据玩家等级自动匹配怪物
- 战斗结果自动计算

**战斗流程**:
```
开始 → 匹配怪物 → 计算伤害 → 判断胜负 → 发放奖励 → 循环
```

**战斗公式**:
```
玩家伤害 = max(1, 玩家攻击 - 怪物防御)
怪物伤害 = max(1, 怪物攻击 - 玩家防御)

战斗回合 = ceil(怪物血量 / 玩家伤害)
总伤害 = 战斗回合 * 怪物伤害

胜利条件 = 总伤害 < 玩家血量
```

### 2. 挂机收益

**在线挂机**:
- 100%效率
- 实时获得经验和灵石

**离线挂机**:
- 最多计算12小时
- 50%效率
- 自动发放奖励

### 3. 境界突破

**突破条件**:
1. 达到当前境界等级上限
2. 支付灵石突破费用
3. 突破成功大幅提升属性

## 🏗️ 游戏系统

### 1. 境界系统

**九大境界**:

| 境界 | 等级范围 | 属性加成 | 突破费用 |
|------|---------|---------|---------|
| 练气期 | 1-9 | 1.0x | - |
| 筑基期 | 10-19 | 1.5x | 1,000 |
| 金丹期 | 20-29 | 2.5x | 5,000 |
| 元婴期 | 30-39 | 4.0x | 20,000 |
| 化神期 | 40-49 | 6.0x | 100,000 |
| 合体期 | 50-59 | 10.0x | 500,000 |
| 大乘期 | 60-69 | 15.0x | 2,000,000 |
| 渡劫期 | 70-79 | 25.0x | 10,000,000 |
| 仙人 | 80-100 | 50.0x | - |

**突破奖励**:
- 属性提升150%
- 解锁新功法
- 解锁新装备

### 2. 功法系统

**功法类型**:
- **攻击型**: 提升攻击力
- **防御型**: 提升防御力
- **辅助型**: 提升修炼速度

**功法品质**:
- 普通（白色）
- 稀有（蓝色）
- 史诗（紫色）
- 传说（橙色）

**功法升级**:
- 消耗灵石升级
- 每级提升加成
- 有最高等级限制

### 3. 装备系统

**装备类型**:
- **武器**: 提升攻击力
- **防具**: 提升防御和生命
- **饰品**: 提升灵力和全属性

**装备品质**:
- 普通、稀有、史诗、传说

**获取方式**:
- 击杀怪物掉落
- 秘境通关奖励
- 商店购买

### 4. 怪物系统

**怪物分级**:
- 普通怪物（1-10级）
- 精英怪物（11-20级）
- 稀有怪物（21-30级）
- Boss怪物（31+级）

**掉落机制**:
- 普通装备: 30%掉落率
- 稀有装备: 10%掉落率
- 史诗装备: 5%掉落率
- 传说装备: 1%掉落率

### 5. 秘境系统（待开发）

**秘境类型**:
- 经验秘境
- 灵石秘境
- 装备秘境

**挑战机制**:
- 消耗灵石进入
- 限时挑战
- 高额奖励

## 📊 数值设计

### 经验系统

**经验公式**:
```
所需经验 = 100 * 1.15^(等级-1)
```

**经验曲线示例**:
| 等级 | 所需经验 | 累计经验 |
|------|---------|---------|
| 1 | 100 | 100 |
| 5 | 174 | 674 |
| 10 | 351 | 2,031 |
| 20 | 1,364 | 12,762 |
| 50 | 73,385 | 428,246 |
| 100 | 10,758,579 | 47,289,642 |

### 属性成长

**每级属性提升**:
- 生命: +10
- 攻击: +2
- 防御: +1
- 灵力: +5

**境界加成**:
- 基础属性 × 境界倍率

### 资源产出

**怪物掉落**:
```
经验 = 怪物等级 * 10
灵石 = 怪物等级 * 5
```

**离线收益**:
```
每分钟收益 = 玩家等级 * 1 经验 + 玩家等级 * 0.5 灵石
最大离线时间 = 12小时
效率 = 50%
```

| 筑基期满级 | 5小时 |

| 大乘期满级 | 30天 |
| 渡劫期满级 | 60天 |

### 资源平衡

**灵石产出**:
- 战斗掉落
- 离线收益
- 任务奖励

**灵石消耗**:
- 功法购买
- 装备购买
- 境界突破

**平衡目标**:
- 每日在线1小时 ≈ 消耗持平
- 每日在线2小时 ≈ 盈余20%
- 挂机24小时 ≈ 盈余50%
