## 🎯 设计原则

### 1. 简洁明了
- 信息层级清晰
- 核心功能突出
- 减少认知负担

### 2. 即时反馈
- 操作有明确反馈
- 状态变化可见
- 进度可视化

### 3. 一致性
- 视觉风格统一
- 交互逻辑一致
- 组件复用

### 4. 可访问性
- 文字清晰可读
- 按钮易于点击
- 色彩对比度足够

## 🎨 视觉设计

### 色彩方案

**主题色**:
- 主色: #FFD700 (金色)
- 辅色: #8B4513 (棕色)
- 强调色: #FF6B6B (红色)

**品质色**:
- 普通: #FFFFFF (白色)
- 稀有: #4169E1 (蓝色)
- 史诗: #9932CC (紫色)
- 传说: #FFA500 (橙色)

**状态色**:
- 成功: #32CD32 (绿色)
- 警告: #FFD700 (黄色)
- 错误: #FF4500 (红色)
