## 📝 文档规范

### 文档命名规范
- 使用大写字母和下划线：`DOCUMENT_NAME.md`
- 文件夹使用小写：`design/`, `api/`
- README作为目录索引

### 文档编写规范
- 使用Markdown格式
- 包含清晰的标题层级
- 添加目录导航
- 使用表格、列表、代码块

### 文档更新规范
- 新功能添加时更新对应文档
- 版本发布时更新CHANGELOG
- 重大变更时更新ROADMAP
